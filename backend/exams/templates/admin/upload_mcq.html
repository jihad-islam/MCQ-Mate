Expected JSON Format

The JSON file must be an array of objects. Each object should define a question with its text, optional explanation, and a list of options.

💡 Pro Tips for Uploading:
- Chapter: System will auto-read chapter_name from the JSON. If missing, it uses the "Default Chapter" selected above.
- Board: You can select a Board from the dropdown to apply it to ALL questions in the file, OR include it in the JSON boards array. 

[
  {
    "text": "$x = \\sqrt{15}$",
    "image_url": "",
    "board_reference": "Dhaka Board 21",
    "chapter_name": "",
    "boards": ["Dhaka Board 2025"],
    "explanation": "Solve for x",
    "options": [
      {"text": "Option A", "is_correct": true},
      {"text": "Option B", "is_correct": false},
      {"text": "Option C", "is_correct": false},
      {"text": "Option D", "is_correct": false}
    ]
  }
]
